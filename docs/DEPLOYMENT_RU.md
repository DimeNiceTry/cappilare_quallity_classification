# Перенос и запуск

## Что переносится через Git

Код, HTML/JS-клиент, финальные веса двух семейств моделей, калибраторы, пороги, численные результаты, аннотации, ноутбук и материалы доклада. Рабочие логи, `.venv`, дублированные экспортные фотографии, промежуточные резервные копии и кэш нейросетевых признаков не входят в Git.

Полные исходные PNG находятся в Release `data-v1`. Скачивание датасета нужно только для просмотра прежних кадров и воспроизведения обучения. Для загрузки и оценки новых фотографий достаточно Git-репозитория и установки зависимостей.

## Windows

1. Установить Python 3.11 или 3.10 x64 и Git.
2. Клонировать репозиторий или скачать исходники через GitHub → Code → Download ZIP.
3. Запустить `setup.cmd`. Скрипт создаст `.venv`, установит зафиксированные зависимости и проверит версии и контрольные суммы весов.
4. Запустить `start_photo_evaluation.cmd`.
5. При необходимости запустить `download_data.cmd`, затем `start_comparison.cmd`.

Повторный запуск установки переиспользует `.venv`. Первое скачивание PyTorch может занять несколько минут. Ни GPU, ни CUDA не нужны.

## Linux и macOS

Создать `.venv` на Python 3.10/3.11, активировать его, выполнить `python -m pip install -r requirements.txt` и `python scripts/check_install.py`. Сервер: `python -m focus_classifier.serve --open`. Данные: `python scripts/download_data.py`.

## Docker

Установить и запустить Docker Desktop/Engine. Из корня репозитория выполнить `docker compose up --build`. Порт опубликован только на локальном интерфейсе: `127.0.0.1:8767`. Веса и код входят в образ, исходные изображения подключаются read-only из `capillary_quality_1000/pictures`.

Если порт занят обычным Python-клиентом, остановить его перед Docker-запуском либо изменить внешний порт в compose.yaml. При изменении порта также нужно передать серверу тот же `--port`, поскольку проверка Host/Origin привязана к порту сервера.

## Воспроизведение без абсолютных путей

`data/annotations/` — основной источник меток текущего эксперимента. Старый `review_client/data/latest_export.json` с путём первоначального компьютера больше не требуется для обучения. Все новые пути определяются относительно корня проекта.

```powershell
.\setup.cmd -Research
.venv\Scripts\python scripts/download_data.py
.venv\Scripts\python -m focus_classifier.extract_features
.venv\Scripts\python -m focus_classifier.train
.venv\Scripts\python -m focus_classifier.neural
.venv\Scripts\python -m focus_classifier.train --neural-only
.venv\Scripts\python -m focus_classifier.report
.venv\Scripts\python -m focus_classifier.benchmark
.venv\Scripts\python -m focus_classifier.write_summary
.venv\Scripts\python -m focus_classifier.build_notebook
```

Переобучение перезаписывает артефакты. Для сохранения опубликованного результата сначала сделать отдельную копию или Git-ветку. Одинаковые seed и версии зафиксированы, но скорость и точное поведение библиотек могут зависеть от платформы.

## Клиент разметки

После скачивания данных можно восстановить завершённую разметку: скопировать два файла из `deployment/review_snapshot/` в `review_client/data/` при остановленном сервере разметки. Затем запустить `start_labeling.cmd`. В снимке уже завершены обе очереди, а исправление клавиш сохранено. Основной клиент оценки новых фотографий от этой базы не зависит.

## Типичные проблемы

- **Python другой версии:** использовать 3.10 или 3.11, чтобы не менять версии библиотек у сохранённых моделей.
- **Нет исходных фотографий в сравнении:** выполнить `download_data.cmd`. Загрузка собственных файлов работает без исходного датасета.
- **«Автодопуск отключён»:** у выбранной модели не найден строгий порог; выбрать MobileNet/ExtraTrees-43 или обычный режим. Это не ошибка установки.
- **Другой размер изображения:** модели проверены на 1024×768. Есть явная пробная опция изменения размера для 4:3.
- **Запуск без интернета:** после установки зависимостей, скачивания данных и Git-репозитория клиент работает локально. Повторное скачивание весов при обработке не требуется.
- **Нельзя воспроизвести аудит eyes:** предыдущий внешний проект не входит в этот репозиторий; сохранён его аудит и результаты. Основной бинарный эксперимент воспроизводится из данного репозитория и Release.
