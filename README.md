# Качество изображений капилляроскопии

Исследование и локальный клиент для предварительного отбора кадров, пригодных для анализа сосудов. Сравниваются четыре исходных показателя резкости, 43 признака качества и MobileNetV3 Small с обученной линейной головой.

**Результат — рабочий прототип предварительного отбора. Полностью автоматический надёжный допуск на новой съёмке пока не подтверждён.**

## Быстрый запуск на другом компьютере

Нужен Python **3.10 или 3.11**, 64 бит. GPU не требуется. Первичная установка скачивает CPU-зависимости; сохранённые веса уже входят в репозиторий.

```powershell
git clone https://github.com/DimeNiceTry/cappilare_quallity_classification.git
cd cappilare_quallity_classification
.\setup.cmd
.\start_photo_evaluation.cmd
```

Клиент откроется на <http://127.0.0.1:8767/upload>. Можно загрузить свои фотографии, выбрать модели и режим отбора, сравнить оценки и скачать CSV. **Для оценки своих фотографий скачивать исходный датасет не нужно.** Файлы обрабатываются локально в памяти.

Linux/macOS:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/check_install.py
python -m focus_classifier.serve --open
```

## Данные и воспроизведение эксперимента

Исходные **1000 PNG (около 1,7 ГБ)** распространяются отдельным [GitHub Release data-v1](https://github.com/DimeNiceTry/cappilare_quallity_classification/releases/tag/data-v1), четырьмя независимыми ZIP-частями. Код загрузки проверяет размеры и SHA-256 всех архивов и фотографий.

```powershell
.\download_data.cmd
.\start_comparison.cmd
```

Или: `python scripts/download_data.py`. Для ручной установки распакуй все четыре ZIP в корень репозитория: изображения должны оказаться в `capillary_quality_1000/pictures/`. Аннотации и результаты уже включены в Git. Инструкции по переобучению и ноутбуку — в [focus_classifier/README.md](focus_classifier/README.md).

## Основные результаты

Пять внешних частей по пациентам; модель не обучалась на пациентах проверяемых кадров. Обучение и оценка бинарной задачи: **62 согласованных хороших и 503 плохих кадра**. Ещё 435 спорных кадров исключены из этих метрик. Один ответ разметчика исторический, другой — перекрёстный; критерии уточнялись.

| Вариант | AUROC | AP | Обычный режим: хорошие / плохие принятые | Строгий режим: хорошие / плохие принятые |
| --- | ---: | ---: | ---: | ---: |
| Линейная модель, 4 признака | 0,880 | 0,468 | 53 / 106 | допуск отключён |
| ExtraTrees, 43 признака | 0,960 | 0,789 | 58 / 69 | 29 / 3 |
| MobileNetV3 + линейная голова | 0,985 | 0,867 | 59 / 34 | 34 / 7 |

Строгий порог выбирался на внутренних пациентах при наблюдаемой precision ≥90% и минимум пяти принятых кадрах. Это правило подбора, а не гарантия 90% на новых данных. ECE вероятности `ok` после калибровки: 0,0203 для ExtraTrees-43 и 0,0231 для MobileNet.

На Intel i5-9300H медиана PNG → решение: 63,5 мс для линейной модели с 4 признаками, 203,0 мс для ExtraTrees-43 и 59,2 мс для MobileNet. Эти измерения относятся к данному CPU и реализации, batch=1; полный лог измерений находится в `focus_classifier/artifacts/speed.json`.

Старые ~65% accuracy в трёхклассовом эксперименте и новые бинарные результаты относятся к разным задачам и выборкам. Их нельзя показывать как прямой рост точности одной модели.

## Ограничения

Набор совпадений обогащён простыми случаями; хороших кадров всего 62 от 41 пациента. Это внутренняя проверка с групповым разделением, а не независимый финальный тест новой съёмки. Нет эталонных масок сосудов и проверки ошибки измерения диаметра. Модели оценивают соответствие текущей разметке пригодности, а не точность морфометрии. Рекомендуемое применение — ранжирование и предварительный отбор с просмотром человеком.
