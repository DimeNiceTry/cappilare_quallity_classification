# Снимок разметки для бинарного эксперимента

Все 1000 кадров имеют человеческую и ассистентскую метку: одну историческую и одну новую перекрёстную. Критерий уточнялся; согласие не равно подтверждённой истинности.

В обучение включены 565 совпавших определённых ответов: 62 ok и 503 not_ok. 415 расхождений и 20 совпавших uncertain исключены из обучения и метрик бинарного качества. `all_comparisons.csv` содержит все пары, `frames.json` и `consensus.csv` — согласованный набор, `reviews_snapshot.json` — новые ответы с версиями критериев.

Исходные исторические метки находятся в `capillary_quality_1000/frames.json`. Они не заменены бинарным консенсусом.
