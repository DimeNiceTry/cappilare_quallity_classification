Локальная перекрёстная разметка 1000 кадров.

Запуск: дважды щёлкнуть `../start_labeling.cmd`. Браузер откроет http://127.0.0.1:8766. Интернет и установка библиотек не нужны; используется Python стандартной поставки.

Пользователю назначены 500 кадров с исходными метками ассистента. Ассистенту — 500 кадров с исходными человеческими метками. Новые ответы собираются отдельно. Исходные PNG и JSON не изменяются.

Критерии от 02.11.2026: различимы границы мелких и крупных сосудов основной сети по всему полю; частичная резкость основной сети неприемлема. По явному уточнению пользователя размытые глубокие фоновые сосуды допустимы при чёткой основной сети. «Не уверен» обозначает неуверенность оценивающего.

Клавиши 1/2/3: годен / не уверен / не годен. Ответ немедленно сохраняется, затем показывается следующий кадр. Для исправления вернуться назад или указать номер кадра, снять флажок «Только неоценённые» при просмотре всей очереди. Причина и комментарий сохраняются вместе с выбранной оценкой. Колесо мыши увеличивает изображение, перетаскивание перемещает его, 0 вписывает в окно, F включает полный экран. Кнопка 1:1 показывает исходный масштаб. Исходный PNG можно открыть отдельно.

Прежние ответы и ответы другого оценщика не передаются в интерфейс до завершения обеих очередей. Во время работы показывается только количество выполненных оценок. Несколько изображений ассистент уже видел при предыдущем аудите; сокрытие меток на текущем этапе не делает весь эксперимент полностью независимым от прежнего контекста.

Каждый новый ответ и история его изменений сохраняются в `data/reviews.sqlite3`; информация об исходной версии данных — в `data/source_snapshot.json`. Копировать папку `data/` для резервного сохранения лучше при остановленном сервере; при работающем сервере SQLite может использовать также файлы `-wal` и `-shm`, поэтому одиночное копирование основного файла не гарантирует полного снимка. В клиенте можно скачать JSON своих ответов.

После завершения 500 + 500 новых оценок откроется сравнение и экспорт. В основной `frames.json` входят только совпадения `ok/ok` и `not_ok/not_ok`, с булевыми метками. `uncertain/uncertain` сохраняется отдельно, все расхождения остаются в отдельном JSON. Экспорт может также скопировать совпавшие PNG в новую папку. Исходные изображения не перемещаются и не удаляются. Наборы сохраняются с уникальными именами в `data/exports/`.

Один ответ на каждый кадр исторический, второй новый. Уточнение критериев могло изменить трактовку качества. Отбор совпадений преимущественно оставляет простые случаи; нельзя оценивать итоговую модель только на нём. Сохраняйте независимый контрольный набор и разделяйте данные по пациентам.

Ручной запуск сервера:

```powershell
python review_client/server.py
```

Проверки сохранения, восстановления, конфликтов вкладок, скрытия меток и экспорта выполняются на временных данных:

```powershell
python -m unittest discover -s review_client -p test_store.py -v
```

`assistant_review.py queue` выводит ассистенту только пути и идентификаторы, без исходных меток. `import --file batch.json` импортирует явно выполненную визуальную оценку. Вероятности обученных моделей при новой разметке не используются.
