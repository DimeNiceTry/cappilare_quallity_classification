# Классификаторы качества капилляроскопии

## Загрузка своих фотографий

Дважды нажать `../start_photo_evaluation.cmd` или открыть `http://127.0.0.1:8767/upload`, если локальный сервер уже запущен. Можно добавить до 50 файлов, выбрать одну или несколько из девяти моделей, строгий/обычный/ручной порог, получить вероятности и решения рядом и скачать CSV. По умолчанию выбраны MobileNet и ExtraTrees на 43 признаках. Клик по фотографии открывает исходное изображение; кнопка 1:1 показывает его без вписывания в окно.

PNG, JPEG, BMP и TIFF до 20 МБ, один 8-битный кадр на файл. Проверенный размер — 1024×768. Для другого размера с пропорциями 4:3 можно явно включить преобразование; результат помечается как пробный после изменения масштаба. Автоматического растягивания кадра другой пропорции нет. TIFF-превью зависит от поддержки формата браузером.

Файлы передаются только локальному процессу на 127.0.0.1, обрабатываются в памяти и сервером не сохраняются. Превью живут в браузере до очистки или закрытия страницы. В CSV попадают имена файлов, оценки моделей, использованный режим/порог, время анализа и пометка известного обучающего кадра.

Используются финальные модели, обученные на всех 565 согласованных кадрах, со своими финальными порогами. Они отличаются от пяти внешних моделей, которыми получены экспериментальные OOF-метрики. Совпадение загруженного файла с обучающим набором отмечается явно. У некоторых моделей строгий порог равен служебному значению 2: интерфейс показывает «Автодопуск отключён», а не объявляет фотографию плохой. У MobileNet и ExtraTrees на 43 признаках строгие пороги доступны.

Первое применение MobileNet загружает локальные веса в память и может занимать несколько секунд. Дальше используется та же сеть. Веса и модельные файлы не скачиваются при обработке фотографий. Время анализа в карточке включает признаки/сеть и классификатор, но не чтение, декодирование или первую загрузку весов. Время всей операции указано отдельно.

Проверки загрузки и совпадения с прямым прогнозом: `python -m unittest focus_classifier.test_upload -v`. Проверка логики интерфейса: `node focus_classifier/test_upload_viewer.cjs`. Браузерный скриншот автоматически не получен; проверены HTTP, реальные предсказания и JS-логика выбора/загрузки/экспорта.

Выполненный ноутбук со сравнением фотографий и объяснениями: [CAPILLARY_COMPARISON_RU.ipynb](CAPILLARY_COMPARISON_RU.ipynb). Готовая автономная копия для браузера: [CAPILLARY_COMPARISON_RU.html](CAPILLARY_COMPARISON_RU.html), интернет и Jupyter для неё не нужны. Оба файла содержат сохранённые графики и фотографии.

В ноутбуке разобраны все модели и метрики, строгий и обычный режимы, шум, пары с близкими значениями резкости, локальный фокус, все ложные допуски строгого отбора ExtraTrees и нейросети, все хорошие кадры, потерянные нейросетью в обычном режиме, расхождения и спорная разметка, ECE и скорость. В конце можно подставить любые имена из 1000 фотографий, выбрать фильтр/порог или одинаковый участок двух кадров. Повторное выполнение читает готовые внешние прогнозы и не переобучает модели.

Зависимости для выполнения ноутбука: `requirements-notebook.txt`. Пересборка с выполнением и HTML-экспортом: `python -m focus_classifier.build_notebook` из корня проекта.

Открыть результат: дважды нажать `../start_comparison.cmd`. Откроется локальная страница `http://127.0.0.1:8767`. На ней можно независимо выбрать модель по четырём признакам, по 43 признакам или нейросетевой вариант, смотреть хорошие/плохие решения, ошибки, расхождения моделей, менять порог и скачивать выбранные строки CSV. Фото открываются в исходном размере кнопкой 1:1. Исходные метки не редактируются.

`artifacts/RESULTS_RU.md` — выводы с фактическими метриками и скоростью. `artifacts/predictions.csv` — 1000 кадров × 10 моделей, вероятности и решения. `features.csv` — все 43 признака, `metrics.json` — подробные метрики и интервалы, `folds.json` — точный состав пациентов и кадров для проверки. `roc_pr.png` и `calibration.png` — графики для экспорта. `PROTOCOL_RU.md` фиксирует план проверки.

На странице и в `predictions.csv` используются прогнозы вне обучения: пациент оцениваемого кадра исключён из внешнего обучения, калибровки и выбора порога. Пять разных внешних моделей дают оценки разных частей, поэтому пороги в строках могут различаться. Только согласованные 62 ok и 503 not_ok участвуют в обучении и оценке качества. Для остальных 435 кадров можно изучить прогнозы, но согласованного правильного ответа для расчёта точности нет.

Для будущих PNG модели обучены на всех 565 кадрах и сохранены отдельно. Запускать из корня проекта:

```powershell
python -m focus_classifier.predict --input "C:\path\to\pictures" --model trees_extended --mode precise --out "C:\path\to\scores.csv"
python -m focus_classifier.predict --input "C:\path\to\pictures" --model logistic_basic --mode balanced --out "C:\path\to\fast_scores.csv"
python -m focus_classifier.predict --input "C:\path\to\pictures" --model neural --mode precise --out "C:\path\to\neural_scores.csv"
```

Каждый вариант независим: `models_features.joblib` используется без PyTorch; нейросетевому нужны `models_neural.joblib` и `mobilenet_v3_small_imagenet.pt`. В варианте neural основная сеть фиксирована, обучена линейная голова. Полного дообучения всех слоёв на этих фотографиях не было. Установленные версии записаны в JSON; зависимости перечислены отдельно для двух вариантов. Повторное скачивание весов при обычном запуске не требуется.

Поддерживается один PNG или каталог PNG в исходном масштабе 1024×768. Признаки резкости зависят от масштаба, поэтому иной размер отвергается явно. Файл результата CLI содержит `p_ok`, порог, `ok` / `not_ok` и пояснение, что используется финальная модель. Для оценки метрик на текущем наборе используйте внешние прогнозы, а не CLI-предсказания модели, обученной на всех 565 кадрах.

Воспроизведение эксперимента:

```powershell
python -m focus_classifier.extract_features
python -m focus_classifier.train
python -m focus_classifier.neural
python -m focus_classifier.train --neural-only
python -m focus_classifier.report
python -m focus_classifier.benchmark
python -m focus_classifier.write_summary
```

Замер скорости запускается после завершения обучения и других тяжёлых вычислений. Batch=1, CPU, чтение PNG включено; отдельно сохраняется время анализа уже декодированного кадра. Это замер обычного Python/PyTorch/OpenCV на текущем компьютере, без ONNX, квантования и оптимизации видеопотока. Загрузка моделей не входит в время одного кадра.

Проверки:

```powershell
python -m unittest focus_classifier.test_experiment -v
node --check focus_classifier/static/app.js
node focus_classifier/test_viewer.cjs
```

Проверены численные метрики, отсутствие пересечения пациентов, обработка отсутствующего строгого порога, прогнозы, фильтры интерфейса, сравнение моделей, CSV и доступ к исходным PNG через HTTP. Автоматический визуальный просмотр в браузере в этой среде недоступен; отрисовка проверена по коду и поведению интерфейса в DOM-заглушке, без браузерного скриншота.

Калибровка и групповые части реализованы с учётом [документации scikit-learn по калибровке](https://scikit-learn.org/stable/modules/calibration.html) и [StratifiedGroupKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedGroupKFold.html). Предобученная модель — [MobileNetV3 Small из torchvision](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.mobilenet_v3_small.html). В ECE используются равные интервалы, взвешенные по числу кадров; отдельно считаются confidence предсказанного класса и вероятность ok. Полная реализация интервалов находится также в `research/evaluate_calibration.py`.
