ФОТОГРАФИИ И РАЗМЕТКА КАЧЕСТВА КАПИЛЛЯРОСКОПИИ

Фотографий: 1000. Видео: 500. Пациентов: 93.
Классы: неок — 509; ок — 281; сомнительно — 210.

СТРУКТУРА
pictures/ — все исходные PNG без уменьшения и перекодирования.
frames.json — объединённая разметка всех фотографий, UTF-8.
patient_map.csv — соответствие video,patient_id для разделения данных.
manifest.json — состав, количество и SHA-256 фотографий и разметки.

ПОЛЯ frames.json
file — имя файла внутри pictures/.
quality_ok: true = ок; false = неок; строка "unknown" = сомнительно.
Сомнительно — третий размеченный класс, а не пропущенная метка.
annotator: human — пользовательская разметка; assistant — дополнительная.
Дополнительную разметку пользователь проверил и одобрил.

КРИТЕРИИ
Ок: сосуды достаточно чёткие и различимы для анализа.
Неок: сильное размытие, засветка, перекрытие или сосуды неразличимы.
Сомнительно: пограничные случаи, где уверенное решение затруднено.

ОБУЧЕНИЕ
Все кадры одного пациента следует оставлять в одной части данных.
Чтобы получить video из имени фотографии, уберите последний суффикс
_номерКадра.png и добавьте .avi; затем сопоставьте его с patient_map.csv.
Для проверки переноса на новых пациентов используйте групповой split.

ПРИМЕР PYTHON
import json
from pathlib import Path
root = Path("capillary_quality_1000")
frames = json.loads((root / "frames.json").read_text(encoding="utf-8"))
image_path = root / "pictures" / frames[0]["file"]
label = frames[0]["quality_ok"]

Архив содержит отдельную копию данных на момент упаковки.
Изменения рабочей разметки после создания архива сюда не попадают.
